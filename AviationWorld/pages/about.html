About Skyline Aviation

A front-end project built with HTML, CSS and vanilla JavaScript. No frameworks, no images, no backend.

FAQ

Is the data live?

No. It is a static dataset in js/data.js, with approximate figures for illustration. Live data would need an external API.

Can I add more aircraft or airlines?

Yes. Add an object to the arrays in js/data.js and every page picks it up automatically.

Does the contact form send email?

No. Sending needs a backend or a form service. This form validates input and shows a confirmation in your browser only.
